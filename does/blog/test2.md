
### 这是我的第一个博客，谢谢你看喵


说实话，做这个网站的过程，真的比我预想中要曲折好多好多。

一开始我琢磨得特别简单：不就一个开发者作品集嘛，放两个 GitHub 项目，加个技术博客，再整个中英文切换。标准套餐对吧？结果刚迈出第一步就被绊倒了。

### 第一关：文字死活不显示

我刚开始用的 React + Babel，想着直接在浏览器里编译 JSX，多方便。结果 Babel 编译的时候老是跟 import 较劲，浏览器根本不认这玩意儿。我反反复复试了好几种方案——从 React 换成 HTM，又从 HTM 换成纯原生 JavaScript，每次刷新页面都盼着文字出来，结果每次都是空白……那几轮下来，我自己都快崩溃了。最后干脆一拍桌子，所有外部依赖全不要了，纯 HTML/CSS/JS 手写。虽然代码写得手酸，但至少稳了，文字再也不会莫名其妙消失了。

### 第二关：换成真人的信息

因为我套的模板库，框架搭好后，就该把占位的假资料换成 ThinkReally114 的真实 GitHub 数据了。我去 GitHub API 那儿拉了仓库列表，挑了俩比较有代表性的——一个是 Source-UI，用纯前端搞了个模拟手机系统界面；另一个是 pvputils-fix，修复了 PVPUtils 在 Linux 上崩溃的问题。然后根据这些项目的真实情况，老老实实写了描述和亮点，又顺着 GitHub 上的活动记录拼出了“关于我”那一段。博客也从首页里单独拎了出来，做成一个 blog.html 页面，整体感觉清爽不少。

### 第三关：博客到底怎么打开

博客列表做好后，刚开始点卡片直接跳到 GitHub 或 Gitee 去了。我自己用了几次，总觉得怪怪的——明明在网站里点开，怎么一下子就飞出去了？于是我又加了个文章阅读视图：点击卡片后，页面会切换到阅读模式，从 GitHub 的 raw 地址拉取 Markdown 内容，然后在页面上渲染出来。为了这个还手写了一个简单的 Markdown 解析器，支持标题、代码块、列表、引用和图片这些常用语法。博客列表的数据源也改成了从仓库里的 BLOGTITLEGUIDING 配置文件读取，以后加新文章只要改那个文件就行，不用再动代码，省心很多。

### 第四关：GitHub Pages 部署卡住不动

代码推上去后，GitHub Pages 一直卡在 deployment_queued 状态，刷新好多遍都没反应。查了一圈才发现，是因为我短时间内连续 push 了好几次，部署任务互相取消了，陷入了死循环……这 GitHub 也是挺迷的。解决办法是加了个 .nojekyll 文件跳过 Jekyll 构建，然后手动触发了一次新部署。等了一会儿终于上线了，那会儿心情真的像卸了块大石头。

### 第五关：动画和交互的细碎打磨

网站能跑起来之后，就开始抠各种小细节了。先给博客卡片做了展开动画，点一下有个过渡效果再显示文章。后来自己越看越觉得多余，干脆改成直接在独立页面显示，简单粗暴。接着折腾导航栏的过渡：在文章页面时，左上角的 “ThinkReally114” 会淡出变成返回按钮，用了透明度加位移的组合，效果还挺自然的。页面切换也加了个滑入滑出的动画，有点像手机 App 那种感觉，手感顺滑不少。

### 第六关：各种奇奇怪怪的小 bug

这部分最磨人，但也最影响体验。比如点任何元素都会冒出一个蓝色边框，那是浏览器的默认 focus 样式，我用 outline: none 干掉了，又补了 -webkit-tap-highlight-color: transparent 去掉移动端的高亮。博客页面底部还留着“用 M3 设计语言手工搭建”那行字，之前说要删但没删干净，这次彻底清掉了。

打字机动画也改了好多遍。一开始名字和 tagline 一起打字，后来觉得太啰嗦，就只给 “ThinkReally114” 加动画，控制在 0.7 秒左右。光标也从一个点号 . 换成正常的竖线，打完字后一直闪，看着舒服多了。结果发现动画期间下面的 tagline、按钮和数据全被清空了，那 0.7 秒页面下半部分是白的……修复起来其实很简单，就是让渲染函数先把这些内容填好，打字机只管名字那一块就行。

### 最后一关：导航栏的毛玻璃效果

最后给导航栏加了高斯模糊。之前只有滚动后才出现背景，静止时是透明的，内容滚过时字都糊在一起看不清。我改成了始终带 70% 透明度的半透明背景，加上 backdrop-filter: blur(20px) 的毛玻璃效果，滚动后背景加深到 85% 再加个阴影。两个页面都同步改了，视觉上舒服多了。

#### 回头想想

整个下来前前后后改了十几次，从最开始技术选型翻车，到功能实现，再到各种细节反复磨。最大的感受就是——别太依赖那些外部库，有时候最笨的办法反而是最可靠的。而且每次改完一定要自己打开页面看一眼，光看代码真的看不出问题。

最后做出来的网站功能不算多，但轻量、没依赖、加载快，该有的都有了：项目展示、博客、中英文切换、暗色模式、响应式，一样不少。
